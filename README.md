# Missão Rover Lunar 🚀

O código realiza uma verificação rápida com base no valor de entrada fornecido para identificar a maioridade.

## 📋 Descrição do Código (`rover.py`)

O arquivo `rover.py` processa uma variável de entrada chamada `idade` e determina se o valor inserido corresponde a alguém **maior de idade** (18 anos ou mais) ou **menor de idade** (menos de 18 anos).

## 🚀 Como Executar o Projeto

Certifique-se de ter o **Python** instalado em sua máquina local.

1. Abra o terminal na raiz do projeto.
2. Certifique-se de que está na branch correta (`develop`).
3. Execute o script com o seguinte comando:

```
python rover.py
```

## 🛠️ Tecnologias Utilizadas

* **Python** - Linguagem de programação interpretada.
